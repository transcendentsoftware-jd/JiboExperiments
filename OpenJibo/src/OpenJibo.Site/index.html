A few good questions

Before you dive in.

Will downloading this bring my robot online?

Not by itself. The preview runs server software on a Linux computer. Connecting a physical Jibo is a separate process, and the right steps depend on his software and setup. Start with the community, or read the technical device guide.

Can I sign up for OpenJibo Cloud?

Not yet. We’re preparing the service and testing its safety and recovery steps. Its planned address is cloud.openjibo.com; public DNS setup is still pending. This page does not promise public signup or pricing.

Do I need to be a programmer?

Not to explore the project or get help with your robot. Testing the server preview does require a native Linux x86_64 computer, Docker, and familiarity with a terminal. We’re working toward easier installers; today’s guide is for tinkerers.

How can I help?

Join the revival community, test a preview in a separate setup, or share a reproducible bug report. Leave passwords, private keys, audio, and personal information out of public reports.
